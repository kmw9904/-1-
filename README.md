# javascript-calculator-precourse

## 구현할 기능 목록 정리`

1. 입출력 기능  
   1.1. `@woowacourse/mission-utils`에서 제공하는 `Console.readLineAsync()`를 활용하여 입력 기능 구현과 `Console.print()`로 입력한 값이 제대로 출력할 수 있는 기능 구현

2. 구분자와 양수로 구성된 입력값을 구분자로 구분하는 로직 기능 구현  
   2.1. 쉼표(,) 또는 콜론(:)을 구분자로 숫자를 분리하는 기능 구현  
   2.2. "//" 와 "\n" 사이에 위치하는 커스텀 구분자를 구현하는 기능 구현  
   2.3. 숫자의 범위가 정해진게 없으니 음수 부호의 숫자 예외처리 기능 구현

3. 구분된 숫자를 가지고 더한 값을 출력 기능  
   3.1. 숫자를 더하고 출력하는 기능 구현  
   3.2. 사용자가 잘못된 값을 입력할 경우 `[Error]`로 시작하는 메시지 출력 기능 구현  
   3.3. `[Error]`가 출력될 경우 Error가 발생 시킨 후 애플리케이션 종료 기능 구현
